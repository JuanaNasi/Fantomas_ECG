# Fantoma ECG

Proyecto de desarrollo de un simulador de señales electrocardiográficas
destinado a generar distintas señales ECG para pruebas y enseñanza.

## Descripción

El dispositivo permite reproducir diferentes bancos de señales ECG
y modificar parámetros de funcionamiento mediante controles físicos.

## Contenido del repositorio

- `software/`: código utilizado por el dispositivo.
- `hardware/`: archivos correspondientes al diseño electrónico y mecánico.
- `docs/`: documentación y memoria técnica del proyecto.
- `images/`: fotografías e imágenes del desarrollo.
